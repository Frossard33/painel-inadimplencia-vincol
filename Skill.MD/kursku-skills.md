# kursku/skills

- Repositório em português com cerca de 2.100 skills, uma pasta por categoria (conteúdo, email, funis, anúncios, SEO, financeiro, jurídico, analytics, operações, IA, cursos, nichos, cloud/DevOps, backend, frontend, segurança, mobile, jogos, etc.).
- Formato: cada skill é um `SKILL.md` com cabeçalho `name`, `description`, `risk`. Instalação no Claude.ai: baixar o `SKILL.md` e enviar em Personalizar > Habilidades. No terminal: `skillshare install` (ver `docs/SKILLSHARE.md` do repositório).
- Observação de qualidade: as categorias em português (ex.: `analytics-dados`, `financeiro-precos`) são índices de títulos com descrição de uma linha; não abri cada skill do pacote. O conteúdo prático que li está em **`frontend/`**.

## Skills de `frontend/` relevantes
| Skill | Para que serve neste painel |
|---|---|
| `audit` | Varredura de acessibilidade, desempenho, tema e responsivo; gera relatório com gravidade, sem corrigir |
| `critique` | Crítica de design: hierarquia, arquitetura da informação, sinais de "cara de IA" |
| `polish` | Passada final: alinhamento, espaçamento, consistência, estados de interação |
| `clarify` | Textos e rótulos claros, sem jargão, mensagens de erro que dizem o que fazer |
| `harden` | Resistência a casos extremos: nomes longos, muitos itens, sem dados, formatos de número/data |
| `normalize` | Alinhar tudo a um sistema de design (tokens de cor, tipografia, espaçamento) |
| `fixing-accessibility` | Nome acessível em todo controle, teclado, foco, contraste, formulários |
| `fixing-motion-performance` / `animate` | Animação segura e leve (usar com moderação) |
| `brand-guidelines` | Aplicar identidade de marca (usar quando chegar o logo da Vincol) |
