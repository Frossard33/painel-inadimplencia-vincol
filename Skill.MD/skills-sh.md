# skills.sh

- Diretório aberto de skills para agentes (Claude Code, Cursor, Codex, Copilot, Windsurf). Instalação: `npx skills add <dono/repositório>`.
- Ranking por instalações. Não há categoria específica para dashboards, gráficos ou acessibilidade.

## Mais relevantes para este projeto
| Skill | Repositório | O que ensina |
|---|---|---|
| frontend-design | anthropics/skills | Paleta de 4 a 6 cores nomeadas, tipografia com escala, estrutura que carrega significado; evitar cartões idênticos, gradientes decorativos, rótulos em caixa-alta espaçada; piso de qualidade: responsivo, foco visível, `prefers-reduced-motion`, contraste |
| web-design-guidelines | vercel-labs/agent-skills | Acessibilidade (rótulos, `button` vs `div`, `aria-live`), foco (`:focus-visible`), números tabulares, `Intl` para moeda/data, estado de filtros na URL, tratar texto longo e estado vazio, `touch-action` |
| ui-ux-pro-max, impeccable | outros | Revisão geral de UI/UX (não lidas por inteiro; avaliar antes de instalar) |
